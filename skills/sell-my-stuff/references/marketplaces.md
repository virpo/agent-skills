# Marketplaces

Suggest two or three that fit the user's city and items. Ask before posting anywhere.

## By region

| Region | Strong general options | Also consider |
| --- | --- | --- |
| United States, Canada | Facebook Marketplace, Craigslist | OfferUp, eBay (shippable items), Nextdoor, Kijiji (Canada) |
| United Kingdom, Ireland | Facebook Marketplace, Gumtree | eBay, Vinted (clothes), DoneDeal (Ireland) |
| Germany, Austria | Kleinanzeigen (DE), Willhaben (AT) | eBay, Vinted |
| France | Leboncoin | Vinted |
| Spain, Italy | Wallapop, Subito (IT) | Vinted |
| Netherlands, Belgium | Marktplaats, 2dehands (BE) | Vinted |
| Poland | OLX | Allegro Lokalnie, Vinted |
| Czechia, Slovakia | Bazoš | Facebook Marketplace, Vinted, Modrý koník (baby and kids gear, SK) |
| Elsewhere | Facebook Marketplace, the largest local classifieds site | eBay, Vinted |

Item type matters as much as region:

- Clothes, shoes, bags: Vinted first.
- Large furniture, bikes, appliances: local pickup sites (Facebook Marketplace, Craigslist, Bazoš, Kleinanzeigen).
- Small, valuable, shippable items (electronics, collectibles): eBay as well as local.
- Very cheap items: one local site, or a free giveaway listing.

Marketplace rules change. If you are unsure whether a site still exists or what it allows, check before recommending it.

## Search URLs for price research

Replace `QUERY` with URL-encoded search terms. These patterns change; if one fails, use the site's own search box in the browser.

- Bazoš: `https://www.bazos.sk/search.php?hledat=QUERY` (or `bazos.cz`). Category results redirect to subdomains such as `sport.bazos.sk`.
- eBay sold listings: `https://www.ebay.com/sch/i.html?_nkw=QUERY&LH_Sold=1&LH_Complete=1` (or the local eBay domain).
- Craigslist: `https://CITY.craigslist.org/search/sss?query=QUERY`
- Facebook Marketplace usually needs a login to search. Ask the user to log in to the browser first, or skip it for research.

## Form notes

### Facebook Marketplace

- Required: photos, title, price, category, condition. Then location, description, and optional brand or model fields.
- Watch for prompts to also post to groups, and for "boost listing" or paid promotion. Leave both off unless asked.
- The interface language may follow the account settings, not the listing language.
- Accounts with little history may hit review holds. Tell the user if a listing goes "pending".

### Craigslist

- Choose the right city site and the "for sale by owner" section.
- Posting usually needs an email confirmation link the user clicks. Some categories charge a small fee; ask before paying.
- Use the "hide email / reply via Craigslist" style contact option unless the user prefers otherwise.

### Bazoš (bazos.sk, bazos.cz)

- Fields: category, title (`nadpis`), description (`popis`), price (`cena`), postcode (`lokalita`), name, phone, email, and a listing password.
- Phone verification by SMS is common; the user enters the code.
- Upload photos first. Wait until every upload preview shows complete before submitting, then check the public listing shows the right number of photos.
- Put the accented title in `nadpis` and repeat key terms without accents early in `popis` so both searches match.
- Post slowly, at least a minute between listings, and avoid deleting and reposting the same item repeatedly, which can trigger blocks.

### eBay

- Use "sold items" search for prices. Decide auction versus fixed price with the user.
- Shipping cost and returns policy are required decisions; ask the user.

### Vinted

- Mostly clothing, shoes, accessories, and small items. Brand, size, and condition fields matter for search.
- Shipping labels are generated by Vinted; the user ships.

### Kleinanzeigen, Leboncoin, OLX, Gumtree, Marktplaats, Wallapop, OfferUp

Classic classifieds forms: category, title, description, price, location, photos. Check for paid "highlight" add-ons on the final screen and leave them off.
